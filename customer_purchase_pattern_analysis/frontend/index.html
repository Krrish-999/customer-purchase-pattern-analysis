                📈 Regression Models Detailed Comparison Table

                Evaluation metrics: R² Score (variance explained, closer to 1.0 is ideal), MAE (Mean Absolute Error in dollars), MSE (quadratic error), and RMSE (penalizes extreme outlier residuals).

                Evaluation metrics: Silhouette Score (ranges from -1 to +1; measures cluster cohesion and separation), Number of Clusters (k), Inertia / WCSS, and Noise / Outlier Points.
